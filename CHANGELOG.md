# Changelog

## 1.0.0 (2026-04-07)

### ✨ Initial Release

- SPA task management dashboard with Vue 3
- Task CRUD operations with card view
- Category management with hierarchical structure
- Role and person management
- Progress logging system
- Smart filtering (search, section, category, status)
- Dashboard statistics (total, open, completed, overdue)
- Responsive modern UI with Bootstrap 5
- Turkish language interface
- Django JSON API (RESTful, no DRF)
- Environment variable configuration support
